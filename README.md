# make-a-pizza
Welcome to Make A Pizza!

NOTE: IF YOU GET A WINDOWS DEFENDER POPUP, JUST CLICK ON MORE INFO AND THEN RUN ANYWAY!!

This is a python terminal game that simulates running your very own pizzeria!
You start off with 1000 dollars. 
Be sure to go into the store and buy dough, cheese, and tomato sauce.
Those are ESSENTIAL for you to begin your pizzeria. If you do not buy those, you will have to restart the game if you waste all your money that way. 

Once you do that, you can gain access to the pizzaria and unlock options like buying decorations (the more decorations, the better your multiplier will be, which is what gets multiplied onto how much money you get per customer) and hiring workers (who do the work for you so you do not have to interact with those annoying customers...).  

You can also serve customers yourself until you get enough money to buy a worker. 
Know that you can only hire one worker at a time.
